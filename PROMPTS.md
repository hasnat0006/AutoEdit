# The prompts I type

Copy them, then change the parts in [brackets].

## Install this kit

> Install the youtube-shorts skill from the WeAreNoCode-YouTube-Editor folder into this project's .claude/skills folder. Then check everything it needs, install what's missing, and run its tests.

## Make a Short

A landscape podcast or interview clip gets the card look of `youtube-shorts/examples/clip-03`:

> Use my youtube-shorts skill to make a Short from [file path]. Use the card look like clip-03, music from [music folder], and add sound effects.

For a vertical phone clip:

> Please use my YouTube Shorts skill to make a Short from [file name]. It's vertical from my phone.

Or cut one out of a longer recording:

> Use my YouTube Shorts skill to cut a Short from [file name], from "[first words]" to "[last words]".

Then add what you know about the clip:

> When I say things like zoom, show a zoom. When I talk about a sound effect, add the sound effect. When I name a number, show it.

## Give notes

Watch the whole thing first, then go through it with timestamps. Plain words work:

> At second 22 you did this. I'd like it to be like that.

> Around second 14 there's a quick flash. That's a mistake. Please take it out.

> This is way too busy, and most of these sounds make no sense.

> Could you please make this a little bit better?

## Make it learn

This is the one that matters. After every round of notes:

> Can you learn from what we did and add it to the skill?

Or short:

> Save this to the skill.
