# videos/

Working folder for each video. Its contents are not tracked by git.

- `videos/<name>/` holds one source video and its cuts, checks, logs and renders. Drop the raw clip here.
- `videos/_shared/sfx/` holds the sound effects the tools use. These files are tracked.
- `videos/_shared/music/` holds the music beds. The MP3s are not tracked. Add them locally. `CREDITS.md` and the `*.beats.json` files are tracked.

Finished Shorts are saved outside the repo, in `E:\AutoEdit\<video>\`.
